# Как поставить yaseo: пошагово

yaseo — открытый инструмент для SEO под Яндекс. Он работает внутри Claude Code: вы пишете обычными словами «проверь мой сайт», а дальше Claude сам вызывает нужные инструменты и отвечает таблицами с доказательствами.

Инструкция рассчитана на тех, кто раньше не работал в терминале. После каждого шага есть проверка. Если проверка не прошла, дальше не идите: загляните в раздел «Если что-то не так» в конце.

## 0. Что понадобится

- **Claude Code** и подписка Claude, в которую он входит: Pro, Max, Team, Enterprise или аккаунт Console. В бесплатный план Claude Code не входит.
- **Банковская карта для Яндекс Облака.** Яндекс берёт плату за обращения к поиску и Wordstat по своему прайсу: https://aistudio.yandex.ru/ru/docs/search-api/pricing. Сам yaseo бесплатный. Перед платным шагом Claude называет, сколько будет обращений, и ждёт вашего «да».
- **Около 15 минут.**

Терминал — это окно, куда вводятся команды. На Mac: программа «Терминал», её можно найти через Spotlight (Cmd + Пробел, набрать «Терминал»). На Windows: PowerShell, найти через меню «Пуск». Команду копируете целиком, вставляете и нажимаете Enter.

## 1. Поставить Claude Code

Официальная инструкция: https://code.claude.com/docs/en/setup

**Mac и Linux** — в терминале:

```
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows** — в PowerShell:

```
irm https://claude.ai/install.ps1 | iex
```

Затем закройте терминал, откройте новый и войдите в аккаунт:

```
claude
```

Откроется браузер, войдите в свой аккаунт Claude. Выйти из Claude Code можно командой `/exit`.

**Проверка.** В новом окне терминала:

```
claude --version
```

Должен появиться номер версии, например `2.1.211 (Claude Code)`. Если терминал отвечает `command not found`, см. пункт 1 в разделе «Если что-то не так».

## 2. Поставить uv

uv — небольшая программа, которая скачивает и запускает yaseo. Если на компьютере нет подходящего Python, uv скачает его сам. Официальная инструкция: https://docs.astral.sh/uv/getting-started/installation/

**Mac и Linux:**

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows** (PowerShell):

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Закройте терминал и откройте новый.

**Проверка:**

```
uv --version
git --version
```

Обе команды должны напечатать номер версии. `git` нужен, чтобы скачать yaseo с GitHub.

- На Mac без `git` система сама предложит установить инструменты разработчика. Согласитесь, дождитесь конца установки и повторите проверку.
- На Windows `git` ставится отсюда: https://git-scm.com/downloads/win

## 3. Получить ключ Яндекса

Ключ выдаёт Yandex AI Studio. Официальная инструкция: https://aistudio.yandex.ru/ru/docs/search-api/quickstart/

1. Откройте https://aistudio.yandex.cloud/platform/ и войдите с Яндекс ID. Это обычный аккаунт Яндекса, как для Почты.
2. **Создайте организацию.** Введите название организации и название облака, нажмите «Открыть AI Studio». Каталог с именем `default` создастся сам.
3. **Привяжите карту.** Кнопка «Привязать платежный аккаунт» справа вверху → «Добавить карту» → номер, срок, CVV → «Привязать». Статус платёжного аккаунта должен стать `ACTIVE` или `TRIAL_ACTIVE`.
4. **Создайте API-ключ.** Кнопка «Создать API-ключ» справа вверху → выберите срок действия → «Создать». Скопируйте **секретный ключ** и сохраните его в надёжном месте, например в менеджере паролей. После закрытия окна его больше не покажут.
5. **Отдельно скопируйте идентификатор каталога.** Наведите указатель на название каталога вверху экрана и нажмите значок копирования (так описано в https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/). Сохраните рядом с ключом.

**Проверка.** У вас записаны два разных значения:
- идентификатор каталога — короткая строка, обычно начинается с `b1g`;
- секретный ключ — длинная строка.

Это разные вещи. Идентификатор самого ключа, который AI Studio тоже показывает, здесь не нужен.

## 4. Поставить плагин в Claude Code

Запустите Claude Code:

```
claude
```

Внутри Claude Code введите по очереди две команды:

```
/plugin marketplace add novyiblog-tech/yaseo
```

```
/plugin install yaseo@yaseo
```

Откроется карточка плагина. Выберите установку для себя во всех проектах (**User scope**) и подтвердите. Если Claude Code напишет `Run /reload-plugins to activate.`, введите:

```
/reload-plugins
```

**Проверка.** Введите `/mcp`. В списке должен быть сервер `yaseo` с пометкой, что он из плагина, и статусом подключения. Первый запуск может занять минуту: uv в это время скачивает yaseo и, если нужно, Python. Если сервер пишет ошибку, см. пункт 2 в разделе «Если что-то не так».

## 5. Вписать ключи

Откройте **отдельное** окно терминала (не внутри Claude Code) и выполните:

```
uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.0 yaseo init
```

Программа спросит по очереди:

1. `YC_FOLDER_ID` — вставьте идентификатор каталога из шага 3.
2. `YANDEX_AI_STUDIO_API_KEY` — вставьте секретный ключ. Ввод скрыт, символы на экране не появятся, так и должно быть. Вставьте и нажмите Enter.
3. `YASEO_DOMAIN` — адрес вашего сайта без `https://`, например `example.ru`. Можно пропустить, нажав Enter.

Ключи запишутся в файл `~/.config/yaseo/.env`, открытый только вашему пользователю. В конце программа предложит одну живую проверку: один платный запрос к Wordstat, цену она назовёт сама. Можно согласиться (`y`) или отказаться (Enter).

**Проверка.** В выводе есть строка:

```
Выдача и Wordstat: готово
```

Если вы согласились на живую проверку, последней строкой будет «Wordstat отвечает: … Всё готово.»

## 6. Первый разговор

Вернитесь в Claude Code. Если он был открыт во время шага 5, перезапустите его: `/exit`, затем `claude`.

Напишите:

> Проверь, настроен ли yaseo

Claude вызовет инструмент `whoami` и перескажет ответ. Там должно быть «Выдача и Wordstat: готово», путь к базе и ваш домен. При первом вызове Claude Code может спросить разрешение на инструмент yaseo. Разрешите.

Затем:

> Проверь мой сайт example.ru

Вместо `example.ru` подставьте свой сайт. Что должно произойти:

- технический аудит: таблица проблем с тяжестью, страницей, доказательством и советом, что сделать. Аудит бесплатный, он читает только страницы вашего сайта;
- готовность к ИИ-поиску: открыт ли сайт ИИ-ботам, есть ли `llms.txt` и разметка. Тоже бесплатно;
- про позиции Claude спросит, по каким запросам вас должны находить, и **до замера назовёт, сколько будет обращений к Яндексу**. Замер пойдёт только после вашего «да».

Ещё примеры:

> Собери семантику для раздела «ремонт квартир»
> Подготовь бриф статьи под запрос «как выбрать ламинат»
> Какие у нас позиции и что изменилось?
> Цитирует ли ИИ-поиск example.ru по запросу «где заказать ремонт квартиры»?
> Дай план, как поднять позиции example.ru

На последнюю фразу Claude соберёт план правок: что мешает индексации, какие страницы уже близко к верху выдачи, где показы есть, а кликов нет. У каждого пункта будет доказательство и готовая инструкция. План бесплатный: он читает ваш сайт и то, что уже накоплено в базе. Чем больше накоплено (позиции, выгрузка Вебмастера из шага 7), тем полнее план.

## 7. Необязательно: Вебмастер и Метрика

Нужно, если вы хотите видеть показы и клики из Вебмастера и поведение из Метрики. Эти отчёты пока запускаются из терминала, а не из разговора с Claude. Claude может запустить их сам, если вы попросите.

Команды ниже начинаются с `uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.0 yaseo`. Если хочется писать короче, один раз выполните `uv tool install git+https://github.com/novyiblog-tech/yaseo@v0.1.0`, и дальше хватит просто `yaseo`.

1. **Создайте приложение** на https://oauth.yandex.ru/client/new (порядок по справке Вебмастера: https://yandex.ru/dev/webmaster/doc/ru/tasks/how-to-get-oauth):
   - название — любое;
   - платформа — «Веб-сервисы»;
   - Redirect URI — `https://oauth.yandex.ru/verification_code`;
   - доступ к данным — `webmaster:hostinfo`, `webmaster:verify` и `metrika:read` (права Метрики: https://yandex.com/dev/metrika/en/intro/authorization).
2. **Скопируйте ClientID и Client secret** приложения и допишите их в файл ключей. Mac: `open -e ~/.config/yaseo/.env`. Windows: `notepad $HOME\.config\yaseo\.env`. Добавьте две строки и сохраните:
   ```
   YANDEX_OAUTH_CLIENT_ID=ваш_ClientID
   YANDEX_OAUTH_CLIENT_SECRET=ваш_Client_secret
   ```
3. **Получите код.** Откройте в браузере адрес, подставив свой ClientID:
   ```
   https://oauth.yandex.ru/authorize?response_type=code&client_id=ваш_ClientID
   ```
   Разрешите доступ. Яндекс покажет код подтверждения. Скопируйте его.
4. **Обменяйте код на токен:**
   ```
   uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.0 yaseo yandex --exchange КОД
   ```
   Токен и токен продления запишутся в тот же файл сами. Токен живёт около полугода, продлевается автоматически.

**Проверка:**

```
uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.0 yaseo yandex --check
```

Строки «Метрика — счётчики» и «Вебмастер — пользователь» должны быть с пометкой `[OK]`. Строка про Директ для SEO не нужна, её `[FAIL]` можно не замечать.

## 8. Необязательно: ключи ИИ-провайдеров

Проверка «цитирует ли ИИ-поиск мой сайт» работает с генеративным ответом Яндекса на тех же ключах, что и в шаге 3. Perplexity, OpenAI, Gemini и Claude можно добавить своими ключами. Каждый из них необязательный.

Откройте файл ключей, как в шаге 7, и допишите нужные строки:

```
PERPLEXITY_API_KEY=...
OPENAI_API_KEY=...
GEMINI_API_KEY=...
ANTHROPIC_API_KEY=...
```

Вместо файла можно задать переменные окружения, yaseo прочитает и их.

**Проверка.** Спросите Claude:

> Какие ИИ-провайдеры настроены в yaseo?

Claude вызовет `geo_providers` и покажет таблицу «провайдер · настроен · каких ключей нет · цена вызова».

Про деньги:

- проверка видимости сначала всегда показывает смету и ничего не тратит;
- тратить она начинает, только когда вы сами назвали провайдеров и согласились;
- генеративный ответ Яндекса дорогой: на 16.09.2026 это 5 080 ₽ за 1 000 запросов, около 5 ₽ за один;
- у зарубежных провайдеров цена зависит от вашего тарифа у них.

Ответы ИИ меняются от раза к разу. Один прогон — снимок, а не приговор.

## Если что-то не так

**1. `command not found: claude` или `command not found: uv`.**
Закройте терминал и откройте новый: установщики дописывают путь к программе, и старое окно его не знает. Не помогло — на Mac и Linux выполните `ls ~/.local/bin`. Если `claude` или `uv` там есть, повторите установку из шагов 1–2 и прочитайте, что установщик пишет в конце: обычно он называет команду, которую нужно выполнить. Для Claude Code есть отдельная страница: https://code.claude.com/docs/en/troubleshoot-install

**2. В `/mcp` сервер `yaseo` с ошибкой, или Claude говорит, что инструментов yaseo нет.**
Сначала проверьте, что yaseo скачивается и запускается. В обычном терминале:
```
uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.0 yaseo --version
```
- Ответ `yaseo 0.1.0` — сам yaseo в порядке. Скорее всего, Claude Code не видит `uv`: так бывает, если Claude Code запущен не из терминала. Закройте Claude Code, откройте новый терминал и запустите `claude` из него.
- Ошибка про `git` — вернитесь к шагу 2 и поставьте `git`.
- Ошибка сети — проверьте интернет и повторите.

После исправления перезапустите Claude Code или введите `/reload-plugins`.

**3. Claude пишет «Не заданы ключи: YC_FOLDER_ID, YANDEX_AI_STUDIO_API_KEY».**
Повторите шаг 5. Если после этого `whoami` показывает у ключа источник «окружение процесса», значит, где-то в настройках системы уже задана такая переменная, и она перекрывает файл. Удалите её или впишите туда верное значение.

**4. Яндекс отвечает ошибкой 401 или 403.**
Чаще всего причина одна из трёх:
- вместо идентификатора каталога вписан идентификатор ключа;
- ключ создан в другом каталоге;
- платёжный аккаунт не активен.

Проверьте все три в AI Studio и повторите шаг 5: Enter оставляет прежнее значение, новое значение заменяет старое.

**5. Wordstat отвечает пусто или ошибкой после серии запросов.**
У Wordstat квота: 100 запросов в час (https://aistudio.yandex.ru/ru/docs/search-api/concepts/limits). Подождите час или разбейте список. Если ошибки похожи на `SSL: UNEXPECTED_EOF_WHILE_READING`, соединение с Яндексом рвётся на пути. yaseo ходит к Яндексу напрямую, мимо системного прокси, но VPN перехватывает весь трафик: выключите его и повторите. И помните: ноль в Wordstat не доказывает, что запрос никто не ищет. Редкие формулировки Wordstat просто не показывает.
