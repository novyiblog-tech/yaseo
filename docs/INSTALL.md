# Как поставить yaseo: пошагово

yaseo работает внутри Claude Code. Вы пишете обычными словами, например «проверь сайт example.ru», а Claude сам вызывает нужные инструменты и отвечает планом правок с доказательствами.

Инструкция написана для тех, кто раньше не работал в терминале. После каждого шага есть проверка. Если проверка не прошла, дальше не идите и загляните в раздел «Если что-то не так» в конце.

## 0. Что понадобится

- Claude Code и подписка Claude, в которую он входит: Pro, Max, Team, Enterprise или аккаунт Console. В бесплатный план Claude Code не входит.
- Минут десять до первой проверки сайта.
- Карта для Яндекс Облака понадобится позже и только если вы захотите позиции, выдачу и Wordstat (шаг 5). Первая проверка сайта бесплатная.

В терминал вводят команды. На Mac это программа «Терминал»: нажмите Cmd + Пробел и наберите «Терминал». На Windows это PowerShell в меню «Пуск». Команду копируете целиком, вставляете и жмёте Enter.

## 1. Поставить Claude Code

Официальная инструкция: https://code.claude.com/docs/en/setup

Mac и Linux, в терминале:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Windows, в PowerShell:

```
irm https://claude.ai/install.ps1 | iex
```

Закройте терминал, откройте новый и войдите в аккаунт:

```
claude
```

Откроется браузер, войдите в свой аккаунт Claude. Выйти из Claude Code можно командой `/exit`.

**Проверка.** В новом окне терминала:

```
claude --version
```

Должен появиться номер версии, например `2.1.211 (Claude Code)`. Если терминал ответил `command not found`, смотрите пункт 1 в разделе «Если что-то не так».

## 2. Поставить uv

Маленькая программа uv скачивает и запускает yaseo. Если подходящего Python на компьютере нет, uv скачает и его. Официальная инструкция: https://docs.astral.sh/uv/getting-started/installation/

Mac и Linux:

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows (PowerShell):

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Закройте терминал и откройте новый.

**Проверка:**

```
uv --version
git --version
```

Обе команды должны напечатать номер версии. `git` нужен, чтобы скачать yaseo с GitHub.

- На Mac без `git` система сама предложит поставить инструменты разработчика. Согласитесь, дождитесь конца установки и повторите проверку.
- На Windows `git` ставится отсюда: https://git-scm.com/downloads/win

## 3. Поставить плагин в Claude Code

Запустите Claude Code:

```
claude
```

Внутри Claude Code введите по очереди две команды:

```
/plugin marketplace add https://github.com/novyiblog-tech/yaseo.git
```

```
/plugin install yaseo@yaseo
```

Откроется карточка плагина. Выберите установку для себя во всех проектах (**User scope**) и подтвердите. Если Claude Code напишет `Run /reload-plugins to activate.`, введите:

```
/reload-plugins
```

**Проверка.** Введите `/mcp`. В списке должен быть сервер `yaseo` с пометкой, что он из плагина, и статусом подключения. Первый запуск может занять минуту: uv в это время скачивает yaseo, а если нужно, и Python. Если сервер пишет ошибку, смотрите пункт 2 в разделе «Если что-то не так».

## 4. Первая проверка сайта

Ключи для этого шага не нужны. Напишите в Claude Code:

```text
Проверь сайт example.ru
```

Вместо `example.ru` подставьте свой сайт. При первом вызове Claude Code спросит разрешение на инструменты yaseo, разрешите.

Что произойдёт:

- Claude обойдёт до 30 страниц сайта с паузами и по правилам robots.txt;
- посмотрит, пускает ли сайт ботов ИИ-поиска, есть ли `llms.txt` и разметка;
- соберёт план правок: что сделать первым, на какой странице и на каком основании;
- напишет, что ничего не потрачено: yaseo обращался только к вашему сайту.

**Проверка.** В ответе есть план с пунктами и строка о том, что ничего не потрачено. Claude может добавить, что позиции и спрос появятся после подключения Яндекса: так и должно быть, это следующий шаг.

Если у Claude есть доступ к коду сайта, можно попросить его выполнить пункт плана. Он покажет изменения и сохранит их только после вашего согласия.

## 5. Подключить Яндекс

Этот шаг нужен для позиций, живой выдачи, Wordstat и генеративного ответа Яндекса. Яндекс берёт плату за обращения по своему прайсу: https://aistudio.yandex.ru/ru/docs/search-api/pricing. Перед каждым платным шагом Claude называет, сколько будет обращений, и ждёт вашего «да».

Ключ выдаёт Yandex AI Studio. Официальная инструкция: https://aistudio.yandex.ru/ru/docs/search-api/quickstart/

1. Откройте https://aistudio.yandex.cloud/platform/ и войдите с Яндекс ID. Это обычный аккаунт Яндекса, тот же, что для Почты.
2. Создайте организацию: введите её название и название облака, нажмите «Открыть AI Studio». Каталог `default` создастся сам.
3. Привяжите карту: кнопка «Привязать платежный аккаунт» справа вверху → «Добавить карту» → номер, срок, CVV → «Привязать». Статус платёжного аккаунта должен стать `ACTIVE` или `TRIAL_ACTIVE`.
4. Создайте API-ключ: кнопка «Создать API-ключ» справа вверху → срок действия → «Создать». Скопируйте **секретный ключ** и сохраните в надёжном месте, например в менеджере паролей. Когда окно закроется, ключ больше не покажут.
5. Скопируйте идентификатор каталога: наведите указатель на название каталога вверху экрана и нажмите значок копирования (так написано в https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/). Сохраните рядом с ключом.

**Проверка.** У вас записаны два разных значения:
- идентификатор каталога: короткая строка, обычно начинается с `b1g`;
- секретный ключ: длинная строка.

AI Studio показывает ещё идентификатор самого ключа. Он здесь не нужен, не перепутайте.

## 6. Вписать ключи

Откройте **отдельное** окно терминала, не внутри Claude Code, и выполните:

```
uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.3 yaseo init
```

Программа спросит по очереди:

1. `YC_FOLDER_ID`: вставьте идентификатор каталога из шага 5.
2. `YANDEX_AI_STUDIO_API_KEY`: вставьте секретный ключ. Ввод скрыт, символы на экране не появятся, так и задумано. Вставьте и нажмите Enter.
3. `YASEO_DOMAIN`: адрес вашего сайта без `https://`, например `example.ru`. Можно пропустить клавишей Enter.

Ключи запишутся в файл `~/.config/yaseo/.env`, открыть его сможет только ваш пользователь. В конце программа предложит одну живую проверку: один платный запрос к Wordstat, цену она назовёт сама. Чтобы согласиться, введите `y`, чтобы отказаться, нажмите Enter.

**Проверка.** В выводе есть строка:

```
Выдача и Wordstat: готово
```

Если вы согласились на живую проверку, последней строкой будет «Wordstat отвечает: … Всё готово.»

Вернитесь в Claude Code. Если он был открыт, перезапустите его: `/exit`, затем `claude`. Напишите:

```text
Проверь, настроен ли yaseo
```

Claude вызовет `whoami`. В ответе должны быть «Выдача и Wordstat: готово», путь к базе и ваш домен.

Теперь можно просить больше:

```text
Проверь сайт example.ru и сними позиции по запросам «ремонт квартир», «ремонт под ключ»
```

```text
Собери семантику для раздела «ремонт квартир»
```

```text
Подготовь бриф статьи под запрос «как выбрать ламинат»
```

```text
Какие у нас позиции и что изменилось?
```

```text
Цитирует ли ИИ-поиск example.ru по запросу «где заказать ремонт квартиры»?
```

Чем больше накоплено (позиции, выгрузка Вебмастера из шага 7), тем полнее план правок.

## 7. Необязательно: Вебмастер и Метрика

Нужно, если вы хотите видеть показы и клики из Вебмастера и поведение из Метрики. Эти отчёты пока запускаются из терминала. Claude может запустить их сам, если попросить.

Команды ниже начинаются с `uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.3 yaseo`. Чтобы писать короче, один раз выполните `uv tool install git+https://github.com/novyiblog-tech/yaseo@v0.1.3`, и дальше хватит просто `yaseo`.

1. Создайте приложение на https://oauth.yandex.ru/client/new (порядок описан в справке Вебмастера: https://yandex.ru/dev/webmaster/doc/ru/tasks/how-to-get-oauth):
   - название любое;
   - платформа «Веб-сервисы»;
   - Redirect URI: `https://oauth.yandex.ru/verification_code`;
   - доступ к данным: `webmaster:hostinfo`, `webmaster:verify` и `metrika:read` (права Метрики: https://yandex.com/dev/metrika/en/intro/authorization).
2. Скопируйте ClientID и Client secret приложения и допишите их в файл ключей. Mac: `open -e ~/.config/yaseo/.env`. Windows: `notepad $HOME\.config\yaseo\.env`. Добавьте две строки и сохраните:
   ```
   YANDEX_OAUTH_CLIENT_ID=ваш_ClientID
   YANDEX_OAUTH_CLIENT_SECRET=ваш_Client_secret
   ```
3. Получите код. Откройте в браузере адрес, подставив свой ClientID:
   ```
   https://oauth.yandex.ru/authorize?response_type=code&client_id=ваш_ClientID
   ```
   Разрешите доступ. Яндекс покажет код подтверждения, скопируйте его.
4. Обменяйте код на токен:
   ```
   uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.3 yaseo yandex --exchange КОД
   ```
   Токен и токен продления запишутся в тот же файл. Токен живёт около полугода и продлевается сам.

**Проверка:**

```
uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.3 yaseo yandex --check
```

У строк `Метрика — счётчики` и `Вебмастер — пользователь` должна стоять пометка `[OK]`. Строка про Директ для SEO не нужна, на её `[FAIL]` можно не смотреть.

## 8. Необязательно: ключи ИИ-провайдеров

Проверка «цитирует ли ИИ-поиск мой сайт» работает с генеративным ответом Яндекса на ключах из шага 6. Perplexity, OpenAI, Gemini и Claude добавляются своими ключами, каждый по желанию.

Откройте файл ключей, как в шаге 7, и допишите нужные строки:

```
PERPLEXITY_API_KEY=...
OPENAI_API_KEY=...
GEMINI_API_KEY=...
ANTHROPIC_API_KEY=...
```

Вместо файла можно задать переменные окружения, yaseo прочитает и их.

**Проверка.** Спросите Claude:

```text
Какие ИИ-провайдеры настроены в yaseo?
```

Claude вызовет `geo_providers` и покажет таблицу: провайдер, настроен ли, каких ключей не хватает, цена вызова.

Про деньги:

- проверка видимости сначала показывает смету и ничего не тратит;
- тратить она начинает, только когда вы сами назвали провайдеров и согласились;
- генеративный ответ Яндекса дорогой: на 16.09.2026 это 5 080 ₽ за 1 000 запросов, около 5 ₽ за один;
- у зарубежных провайдеров цена зависит от вашего тарифа.

Ответы ИИ меняются от раза к разу. Один прогон даёт только снимок, по нему одному выводов не делают.

## Если что-то не так

**1. `command not found: claude` или `command not found: uv`.**
Закройте терминал и откройте новый: установщик дописывает путь к программе, а старое окно о нём не знает. Не помогло? На Mac и Linux выполните `ls ~/.local/bin`. Если `claude` или `uv` там лежат, повторите установку из шагов 1–2 и прочитайте, что установщик пишет в конце: обычно там названа команда, которую нужно выполнить. Для Claude Code есть отдельная страница: https://code.claude.com/docs/en/troubleshoot-install

**2. В `/mcp` у сервера `yaseo` ошибка, или Claude говорит, что инструментов yaseo нет.**
Сначала проверьте, что yaseo скачивается и запускается. В обычном терминале:
```
uvx --from git+https://github.com/novyiblog-tech/yaseo@v0.1.3 yaseo --version
```
- Ответ `yaseo 0.1.3` значит, что с самим yaseo всё в порядке. Скорее всего, Claude Code не видит `uv`: так бывает, когда Claude Code запущен не из терминала. Закройте его, откройте новый терминал и запустите `claude` оттуда.
- Ошибка про `git`: вернитесь к шагу 2 и поставьте `git`.
- Ошибка сети: проверьте интернет и повторите.
- `/plugin marketplace add` или `/plugin install` пишут `Failed to clone`, `SSL_ERROR_SYSCALL` или `Host key verification failed`: соединение с GitHub оборвалось или адрес ушёл по SSH. Проверьте, что в команде полный адрес `https://github.com/novyiblog-tech/yaseo.git`, и повторите.

После исправления перезапустите Claude Code или введите `/reload-plugins`.

**3. Claude пишет «Не заданы ключи: YC_FOLDER_ID, YANDEX_AI_STUDIO_API_KEY».**
Для проверки сайта и плана это нормально, они работают без ключей. Для позиций, выдачи и Wordstat пройдите шаги 5 и 6. Если после шага 6 `whoami` показывает у ключа источник «окружение процесса», значит, в настройках системы уже задана такая переменная и она перекрывает файл. Удалите её или впишите туда верное значение.

**4. Яндекс отвечает ошибкой 401 или 403.**
Обычно причина одна из трёх:
- вместо идентификатора каталога вписан идентификатор ключа;
- ключ создан в другом каталоге;
- платёжный аккаунт не активен.

Проверьте всё это в AI Studio и повторите шаг 6. Enter оставляет прежнее значение, новое заменяет старое.

**5. Wordstat отвечает пусто или ошибкой после серии запросов.**
У Wordstat квота: 100 запросов в час (https://aistudio.yandex.ru/ru/docs/search-api/concepts/limits). Подождите час или разбейте список. Ошибки вида `SSL: UNEXPECTED_EOF_WHILE_READING` значат, что соединение с Яндексом рвётся по дороге. yaseo ходит к Яндексу напрямую, мимо системного прокси, но VPN перехватывает весь трафик: выключите его и повторите. И помните, что ноль в Wordstat ещё не значит, что запрос никто не ищет: редкие формулировки Wordstat просто не показывает.
